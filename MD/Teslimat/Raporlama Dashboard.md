# Raporlama / Looker Studio Dashboard

## Bölümler
1. Özet Pano — tüm KPI'lar tek bakışta
2. Reklam Performansı — Meta ve Google ayrı
3. Landing Page Analizi — trafik, bounce rate, dönüşüm
4. Müşteri Edinimi — lead sayısı, maliyet, kalite
5. Aylık Trend — büyüme grafikleri

> Otomasyon: Looker Studio raporları otomatik PDF olarak email'e gönderilebilir.

## Genel Dashboard İhtiyacı (Kansabi OS fikri ile bağlantılı)
Marketing + SEO + CRO + Ads tek panelde: traffic sources, conversion rates, funnel drop-off, campaign ROI, SEO rankings, GEO visibility signals.
