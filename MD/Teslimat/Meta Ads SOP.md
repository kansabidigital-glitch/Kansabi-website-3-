# Meta Ads SOP

## Onboarding Kontrol Listesi
- [ ] Meta Business Manager erişimi
- [ ] Reklam hesabı kontrolü (kredi limiti, ödeme yöntemi)
- [ ] Meta Pixel kurulumu/doğrulaması
- [ ] Conversions API (CAPI) kurulumu
- [ ] Özel dönüşüm olayları (Lead, Purchase vb.)
- [ ] Mevcut kampanya analizi
- [ ] Hedef kitle araştırması
- [ ] Hesap sınırlamaları kontrolü

## Kampanya Yapısı (Başlangıç)
```
Kampanya 1: TOFU — Farkındalık/Trafik
  ├── Ad Set 1: Geniş hedefleme
  └── Ad Set 2: İlgi alanı hedeflemesi
Kampanya 2: BOFU — Dönüşüm
  ├── Ad Set 1: Retargeting — website ziyaretçileri
  └── Ad Set 2: Retargeting — sosyal medya etkileşimi
```
Her ad set için min. 3 reklam varyasyonu (video + statik kombinasyonu).

## Optimizasyon Takvimi
| Gün | Aksiyon |
|---|---|
| 1–3 | Yayına al, müdahale etme (öğrenme süreci) |
| 4–7 | İlk veri analizi |
| 7–14 | Düşük performanslı setleri kapat |
| 14+ | Kazananları ölçeklendir |
