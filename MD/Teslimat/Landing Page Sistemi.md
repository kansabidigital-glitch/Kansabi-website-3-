# Landing Page Sistemi

## Araçlar
Webflow (premium), Framer (hızlı modern), Spline+Framer (3D), WordPress+Elementor (mevcut WP), Shopify (e-ticaret)

## Zorunlu Elementler
- [ ] Güçlü başlık (benefit odaklı, <8 kelime)
- [ ] Alt başlık
- [ ] Sosyal kanıt
- [ ] Ana CTA — üst kısımda
- [ ] Form/iletişim mekanizması
- [ ] Video/görsel
- [ ] SSS
- [ ] İkinci CTA — altta
- [ ] Güven rozetleri
- [ ] Mobil uyumluluk
- [ ] Hız testi (PageSpeed Insights)

## CRO Kontrol Listesi
- [ ] Form alanı min (max 3-4 alan)
- [ ] CTA eylem kelimesiyle başlıyor
- [ ] Sayfa 3 saniyede yükleniyor
- [ ] Mobil = masaüstü kalitesinde
- [ ] A/B testi kurulu (başlık/CTA/görsel)
