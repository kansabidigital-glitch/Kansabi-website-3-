# Onboarding Akışı

```
Sözleşme İmzalandı → Stripe Ödeme Alındı → Onboarding Formu Gönderildi
→ Müşteri Formu Doldurdu → Erişimler Talep Edildi
→ İç Kick-off (15dk, ekiple) → Müşteri Kick-off (30dk)
→ İlk 7 Gün Planı Paylaşıldı → Teslimat Başladı
```
