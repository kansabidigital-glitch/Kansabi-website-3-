# Tipografi

İki versiyon arası fark için bkz. ~~[[eski-cakisma-notu]]~~ — tipografi de renk versiyonuna bağlı değişiyor.

**V1 (Zen Altın) yönü:** Serif ağırlıklı, Cormorant Garamond / Playfair başlıklarda, Inter gövdede.
**V2 (Nötr Gri / Brand Board) yönü:** Tamamen Inter / System UI, weight 300–600, display'lerde negatif letter-spacing (-0.02em / -0.03em), label'larda +0.15–0.18em uppercase tracking.
